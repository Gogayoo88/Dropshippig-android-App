# Vârf Robot 6

Proiect separat, construit ca versiune experimentală independentă de Vârf Robot 5.

- Interval strict: −10% până la +1% pentru crypto și acțiuni.
- Crypto: tickere publice Revolut X EEA, confirmate cu date de la Revolut X, Binance, Coinbase, Kraken, OKX, Bybit, Bitstamp și KuCoin atunci când acestea sunt disponibile.
- Acțiuni: Yahoo Finance plus Finnhub, Twelve Data, Alpha Vantage, Massive și Alpaca; cheile API lipsă sunt afișate ca indisponibile, nu ca confirmări.
- Filtru de stabilitate: minimum 3 confirmări pozitive, momentum pozitiv, RSI 40–68 și volum relativ cel puțin 1×; crypto cere minimum 4 surse active. Pentru active între 0% și +1%, volumul trebuie să fie ≥1,20×.
- Nu sunt predicții garantate. Datele trebuie validate în utilizare reală și prin backtesting.

Aplicația este PWA și poate fi instalată pe telefon după publicare.
