# Vârf Robot 5

Crypto scanează activele publice Revolut X EEA, filtrează −10%…0% și verifică toți candidații cu surse multiple. Acțiunile folosesc universul Nasdaq/NYSE/otherlisted când sursele răspund. Sursele API neconfigurate nu sunt numărate ca confirmări.

Aplicația este PWA și poate fi instalată pe telefon după publicare.
